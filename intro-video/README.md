# intro-video

Fonte Remotion da intro do portfólio (fora do build Astro).

Cenas: hero → experiências → tecnologias → projetos de laboratório → CTA.  
Visual alinhado a `tokens.css` / `design.md` (paper/hero, accent `#FF7518`, Bricolage + Geist).

## Setup

```bash
cd intro-video
npm install
```

## Preview

```bash
npm run studio
```

## Render

```bash
npm run render
```

Gera `out/intro.mp4` e copia para `../public/videos/intro.mp4` (versionado, servido pelo site).

## SFX

Pixabay (Universfield):

- `public/sfx/click.mp3` — clique do cursor no nome
- `public/sfx/whoosh.mp3` — transição entre cenas
